# SEND_EMAIL Skill

```yaml
id: SKILL_SEND_EMAIL
name: SEND_EMAIL
category: Brahma
description: "Sends an email to a specified recipient with a subject and body."
paramSpec: '{"to": "string (recipient email address)", "subject": "string", "body": "string"}'
```

**Description:**
Allows the agent to send emails directly from the user's connected Gmail account.

**Use Case:**
- "Send an email to user@example.com saying hello"
- "Draft and send an email to boss@company.com with the project report"
