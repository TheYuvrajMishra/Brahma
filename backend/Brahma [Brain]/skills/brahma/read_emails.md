# READ_EMAILS Skill

```yaml
id: SKILL_READ_EMAILS
name: READ_EMAILS
category: Brahma
description: "Reads the most recent emails from the connected Gmail account. Can optionally accept a search query."
paramSpec: '{"maxResults": "number (optional, default 3)", "query": "string (optional Gmail search query)"}'
```

**Description:**
Allows the agent to read emails directly from the user's Gmail inbox.

**Use Case:**
- "Read my latest emails"
- "Do I have any emails from John?"
- "Read my last 5 emails"
